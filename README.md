TVB Autonomous Lead Sourcing AgentThis is a tool designed to automatically hunt down tech startups outside the US that have recently raised between $1M and $5M in seed funding. Instead of spending hours Googling and digging for contact info, this agent handles the repetitive search pipeline for you.  What it actually doesYou tell the app how many leads you want, and it takes care of the rest:  Searches the web: It uses the Tavily API to find news and data about newly funded startups.  Extracts the details: It hands the search results over to Google's Gemini AI, which reads through the text to pull out the company name, founder, what they do, and their exact funding amount.  Hunts for contact info: It concurrently crawls up to 5 pages of the company's website to find contact emails.  Verifies the inbox: Before giving you an email, it checks the live DNS MX records to make sure the email address can actually receive mail.  What you need to run itTo get this working on your machine, you will need to grab two API keys:  A Google Gemini API keyA Tavily Search API keyOnce you have those, just paste them directly into the top configuration section of the discovery_engine.py file.  How to start it upInstall the necessary Python packages by running:pip install -r requirements.txt  Boot up the user interface by running:streamlit run app.py  Your browser will open the dashboard. Just use the sidebar slider to pick how many leads you want, and hit the Trigger Autonomous Run button.  Tweaking the engineIf you want to change the agent's behavior, open up discovery_engine.py. Right at the top, you can change the $1M to $5M funding boundaries, adjust the scraping timeouts, or change how deep it digs into company websites.
